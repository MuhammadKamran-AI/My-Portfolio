# Muhammad Kamran Portfolio

A responsive personal portfolio website built with HTML and CSS. It presents a short introduction, skills, contact details, and social links.

```text
├── index.html
├── css/

├── js/

    ├── about_img.png
    ├── hero-bg.png
    └── profile.png
```

## Run Locally

Open `index.html` directly in a browser, or use a local static server such as the VS Code Live Server extension.

## Deploy on GitHub Pages

1. Create a GitHub repository and upload the contents of this project folder.
2. Keep `index.html` at the root of the selected GitHub Pages source folder.
3. Open **Settings > Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing the project and the `/ (root)` folder, then save.
6. Open the generated GitHub Pages URL after the deployment finishes.

The navigation uses relative paths, so the Home link works when the project is hosted in a repository subpath as well as when it is served locally.
